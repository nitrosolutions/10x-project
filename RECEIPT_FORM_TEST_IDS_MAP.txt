                           USER JOURNEY MAP

═════════════════════════════════════════════════════════════════════════════

Step 1: Navigate to form
        └─ Verify: receipt-form-container exists

Step 2: Select Purchase Date
        ├─ Click: receipt-date-trigger
        └─ Result: receipt-date-calendar appears

Step 3: Fill Store Name (optional)
        └─ Type: receipt-store-name-input

Step 4: Add Receipt Item
        ├─ Click: receipt-add-item-button
        └─ Result: receipt-item-row-0 appears

Step 5: Fill Item Details
        ├─ Type Product Name
        │  └─ receipt-item-row-0-product-name-input
        ├─ Type Price
        │  └─ receipt-item-row-0-price-input
        └─ Select Category
           ├─ Click: receipt-item-row-0-category-select
           └─ Click: receipt-item-row-0-category-option-{ID}

Step 6: Verify Total Updates
        └─ Check: receipt-total-amount contains new value

Step 7: Save Receipt
        ├─ Click: receipt-submit-button
        └─ Result: Page redirects to /?month=YYYY-MM

OR: Cancel Receipt
        ├─ Click: receipt-cancel-button
        └─ Result: Page redirects to home


═════════════════════════════════════════════════════════════════════════════

                        ITEM MANAGEMENT SCENARIOS

═════════════════════════════════════════════════════════════════════════════

Add Multiple Items:
  Step 1: receipt-add-item-button
         └─ receipt-item-row-0 appears

  Step 2: receipt-add-item-button (again)
         └─ receipt-item-row-1 appears

  Step 3: receipt-add-item-button (again)
         └─ receipt-item-row-2 appears


Delete Item (with confirmation):
  Step 1: Click receipt-item-row-{N}-delete-button
         └─ receipt-item-row-{N}-delete-dialog appears

  Step 2a (Cancel): Click receipt-item-row-{N}-delete-dialog-cancel
                   └─ Dialog closes, item remains

  Step 2b (Confirm): Click receipt-item-row-{N}-delete-dialog-confirm
                    └─ Item removed, remaining items reindex


Edit Item (Update field):
  Step 1: Type in receipt-item-row-{N}-product-name-input
  Step 2: Type in receipt-item-row-{N}-price-input
  Step 3: receipt-total-amount updates automatically
