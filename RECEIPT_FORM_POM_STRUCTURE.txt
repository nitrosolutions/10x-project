WHY COMPOSITION?

✓ ReceiptItemRowSection needs new instance per item
✓ Different index for each item (0, 1, 2, ...)
✓ Easy to get specific item: getItemRow(0), getItemRow(1)
✓ Clear separation of concerns

vs

✗ Inheritance would require:
  - Static item count
  - Complex indexing logic
  - Single item per page object
  - Violation of Single Responsibility Principle


COMPOSITION PATTERN:
